## Working notes from this session

- Scripts expect `/tmp/repo` (symlink to the clone) and `/tmp/black_metropolis.db`. Always `export BM_DB=/tmp/black_metropolis.db`.
- Run pipeline scripts with `python3 -I`, except `build_viewer.py`, which needs `python3 build_viewer.py` from `pipeline/`.
- **Full rebuild order** (after any change to extractions): copy `black_metropolis.db` to `/tmp`, then import_1811_directory, import_1838_register, match_names, load_extractions, load_coppin, load_storymaps, split_nichols, split_swilliams, split_bassett, split_appearances, apply_merges, load_nolibs, load_ugrr, load_blogs, load_mobstats, apply_merges, find_merge_candidates, build_viewer. Then copy `index.html` to `1838_black_metropolis_viewer.html`, copy the DB back, and run `node pipeline/smoke_test.js index.html` (4 OK lines is normal).
- For template, lane or `event_orgs.json` changes only, `build_viewer.py` alone is enough. For `merges.json`, run `apply_merges.py` then `build_viewer.py`.
- **Merges must be keyed by name and source, not by id.** An id-keyed merge did not survive a clean rebuild.
- An attendee can be pinned to a specific person with a third element, the person id (used for William White, Winch id 2792). Use this when a name would otherwise match the wrong same-name record.
- Events from books carry an empty `issue`; put scan paths (`manuscripts/...jpg`) in the description and the viewer turns them into "view p.N" links.
- **Drive sync:** tar the files changed in the commit, send the tarball, commit it into `_to_delete/`, then on the device extract to a temp folder and `cp -rf` over the working folder. Deletes are not permitted on the device. There are about a dozen `sync_*.tgz` files in `_to_delete/` from this session that Michiko can delete.
- The Drive folders connected this session: `1838 Names Database`, `Christian Recorder`, `Early Churches`.
