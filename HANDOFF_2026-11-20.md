## Working notes

- **Paths:** scripts expect `/tmp/repo` (a symlink to the clone) and `/tmp/black_metropolis.db`. Always `export BM_DB=/tmp/black_metropolis.db`.
- **Running scripts:** use `python3 -I` for pipeline scripts. The exception is `build_viewer.py`, which runs as `python3 build_viewer.py` from `pipeline/`.
- **Full rebuild order** (after any change to extractions):
  1. Copy `black_metropolis.db` to `/tmp`.
  2. Run, in order: import_1811_directory, import_1838_register, match_names, load_extractions, load_coppin, load_storymaps, split_nichols, split_swilliams, split_bassett, split_appearances, apply_merges, load_nolibs, load_ugrr, load_blogs, load_mobstats, apply_merges, find_merge_candidates, build_viewer.
  3. Copy `index.html` to `1838_black_metropolis_viewer.html`.
  4. Copy the DB back.
  5. Run `node pipeline/smoke_test.js index.html`. Four OK lines is normal.
- **Smaller changes:**
  - Template, lane or `event_orgs.json` changes only: `build_viewer.py` alone is enough.
  - `merges.json` changes: run `apply_merges.py`, then `build_viewer.py`.
- **Merges and split rules must be keyed by name and source, not by newspaper record id.** Newspaper ids change between rebuilds. Winch ids are stable.
- **Pinning an attendee:** add a third element with the person id when a name would otherwise match the wrong same-name record.
- **Events from books** carry an empty `issue`. Put the scan paths (`manuscripts/...jpg`) in the description, and the viewer turns them into "view p.N" links.
- **Ad crops:** set the box against the high-resolution render from the film, not the page JPEG. The two can be offset by a few percent.
- **Drive sync:**
  1. Tar the changed files, split into 12 MB parts, and commit the parts into `_to_delete/`.
  2. On the device, extract to a temp folder, then `cp` over the working folder. Deletes are not permitted on the device.
  3. The `_to_delete/` folder holds many old sync parts that Michiko can delete.
